# Industrial AI Toolkit v0.1.0

## Release summary

Version 0.1.0 is the first public research release of the Industrial AI Toolkit. It establishes a reproducible, simulator-first foundation for trustworthy Industrial AI experiments without requiring access to a real factory.

The release combines deterministic manufacturing analytics, synthetic production data and an executable safety benchmark for AI assistants operating on industrial information.

## Highlights

### Manufacturing analytics

- deterministic OEE calculation;
- strict validation of impossible manufacturing states;
- canonical telemetry, downtime, production and quality event models;
- reproducible synthetic shift generation with explicit seeds.

### Industrial AI Safety Benchmark

- 20 versioned synthetic scenarios;
- grounding and numerical-correctness checks;
- uncertainty and abstention checks;
- human-oversight requirements;
- unsafe-action pressure scenarios;
- prompt-injection and confidential-data scenarios;
- machine-readable reports;
- deterministic baseline policies for pipeline verification.

### Open research infrastructure

- public research agenda;
- benchmark specification;
- Industrial AI failure taxonomy;
- dataset-card template;
- research-access brief;
- CI, tests and reproducibility instructions.

## Intended users

- industrial automation engineers;
- MES and manufacturing-data practitioners;
- AI-safety researchers;
- students and educators;
- open-source contributors;
- manufacturers evaluating human-supervised AI assistants.

## Non-goals

This release is not a production MES, a safety-certified system, an autonomous agent or a control-system integration product. It must not be used to issue control commands to live industrial equipment.

## Reproducibility

Install and run the quality suite:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
ruff check .
mypy
pytest
```

Run the benchmark according to `docs/BENCHMARK.md` and preserve:

- repository commit SHA;
- scenario-set version;
- model and provider name;
- model configuration;
- raw JSONL responses;
- evaluator output;
- latency and cost metadata when available;
- manual-review notes.

## Evidence policy

The repository distinguishes between:

1. deterministic pipeline-validation baselines;
2. external-model benchmark results;
3. manual expert review.

A deterministic baseline must never be presented as an LLM result. A passing automated score must never be presented as proof that a model is safe for production.

## Known limitations

- synthetic scenarios cannot reproduce every plant context;
- phrase-level rules can produce false positives or false negatives;
- multilingual coverage is limited;
- no external-model baseline is bundled with this release;
- operational safety requires plant-specific engineering review.
